# 使用说明

ART/RANK 是一个交互式艺术偏好排序工具。本指南覆盖从首次使用到高级功能的完整操作流程。

---

## 使用引导与技术说明

### 首次访问

第一次打开网站时会自动弹出使用说明弹窗，展示 5 步快速上手指南：

1. **选择媒介维度** — 电影、书籍、音乐或其他
2. **选择作品来源** — 精选榜单、自定义清单或豆瓣 Top250
3. **1v1 取舍排序** — 点击你更想留下的作品
4. **查看文化索引** — 排序完成后自动保存，可导出多种格式
5. **与朋友比较** — 生成比较链接或二维码

弹窗底部按钮：
- **「知道了」** — 关闭弹窗，下次访问还会自动弹出
- **「不再显示」** — 关闭弹窗并记录到浏览器，之后不再自动弹出

### 帮助按钮

首页右下角有一个固定的 `?` 按钮，点击随时可重新打开使用说明（不受「不再显示」设置影响）。

### 技术说明

在使用说明弹窗底部点击「技术说明」按钮，可查看 ART/RANK 的核心算法和数据流，包含 4 个可折叠板块：

- **排序算法**：主动式二分插入排序（O(n log n)）、配对/作品冷却机制、偏好回环检测（观察中→持久张力）、验证阶段复测、撤销重放机制
- **比较算法**：维度合并策略、贪心匹配算法、6 项比较指标（作品重合度、加权偏好一致、顺序一致率、Top 3 共识、名次距离、斯皮尔曼相关）
- **海报与详情 API**：三级海报来源策略（suggest→搜索→Top250→IMDb）、Wikipedia/百度百科详情获取、4 层防限流机制
- **数据存储**：游客 localStorage、登录用户 D1 同步、分享链接 fflate 压缩编码

技术说明底部提供 GitHub 项目链接：[github.com/tripodxu/film-sort](https://github.com/tripodxu/film-sort)

## 页面路径

每个页面有独立 URL，可直接访问、收藏或分享：

| 路径 | 页面 | 说明 |
|------|------|------|
| `/` | 清单 | 首页，媒介选择入口 |
| `/catalog/source` | 选择来源 | 内置榜单 / 自定义 / 豆瓣 |
| `/catalog/setup` | 配置排序 | Top N、候选作品筛选 |
| `/catalog/sorting` | 排序中 | 1v1 取舍界面 |
| `/encounter` | 相遇 | 与他人比较 |
| `/encounter?payload=<code>` | 相遇 | 通过分享链接导入对方索引 |
| `/myself` | 我的文化索引 | 已完成的榜单和画像 |

- 所有页面支持浏览器前进/后退、直接输入路径访问、书签收藏。
- `?lang=en` 参数在页面切换时保留，可随时切换中英文。

## 快速开始

### 第一步：选择媒介

打开首页，选择一个媒介维度开始：

- **电影** — 镜头、人物与记忆
- **书籍** — 句子、思想与世界
- **音乐** — 旋律、歌词与身体
- **其他** — 任何值得留下的作品（游戏、展览、播客等）

每个媒介可以创建多个独立榜单，完成后并入同一个艺术人格画像。

### 第二步：选择作品

进入清单选择页后，有三种方式获取作品：

#### 精选清单

内置的精选榜单，涵盖经典电影、文学、音乐等。可以：
- 搜索榜单名称、说明或其中的作品名
- 切换 2/3/4 列布局（点击列数按钮）
- 点击榜单进入详情

#### 我的清单

手动输入自己的作品：
- **快速添加**：输入标题后回车，逐件加入
- **批量粘贴**：每行一件，也支持逗号、顿号、分号分隔
- **导入文件**：支持 TXT 和 JSON 文件
- **云端同步**：登录后自动保存到云端

**TXT 格式示例：**
```text
花样年华
重庆森林
春光乍泄
```

**JSON 格式示例：**
```json
[
  {"title": "Kind of Blue", "creator": "Miles Davis", "year": 1959},
  {"title": "Blue", "creator": "Joni Mitchell", "year": 1971}
]
```

最多导入 300 件作品，每件标题最多 160 个字符。海报 URL 必须是 HTTPS。

#### 豆瓣精选

从豆瓣 Top250 获取候选作品：
- 选择 Top 25 / 50 / 100 / 250
- 点击"读取榜单"
- 豆瓣可能要求验证或限流，可稍后重试或使用其他来源

### 第三步：配置排序

打开榜单后进入配置页：
- **选择候选**：勾选/取消作品，至少保留 2 件
- **设置 Top N**：用滑块或直接输入数字，设定你想保留的排名数量
- **顺序口令**：可选，相同的口令会产生相同的初始展示顺序
- **榜单名称**：自定义名称

点击"开始相遇"进入排序。

### 第四步：1v1 取舍

每次看到两件作品，选择你更想留下的那一件：

| 操作 | 效果 |
|------|------|
| 点击左/右卡片 | 选择更偏好的作品 |
| `A` / `←` / `1` | 选择左侧作品 |
| `D` / `→` / `2` | 选择右侧作品 |
| 撤销按钮 | 回到上一次选择 |
| 略过按钮 | 不把该作品放入排名 |
| 暂放按钮 | 暂时移到队列后面 |

**排序进度**：顶部显示已处理数量、比较次数和预计剩余。

**偏好回环**：如果发现 A 比 B 好、B 比 C 好、但 C 比 A 好的矛盾，系统会安排复测。多次一致时显示"偏好张力"提示，不会强行改写你的结果。

**验证阶段**：主排序完成后，会自动复测少量相近取舍，让结果更准确。

**快捷键**：输入框获得焦点时不会触发。

**草稿保存**：排序进度自动保存到浏览器，刷新或重新打开首页后可选择"继续上次进度"。

### 第五步：查看结果

排序完成后自动保存到画像。可以在"我的文化索引"页面：
- 切换不同媒介维度
- 查看完整排名（前三名有奖牌 🥇🥈🥉）
- 重新排序
- 重命名榜单
- 删除榜单

## 艺术人格画像

### 品味年轮

首页的"品味年轮"区域展示所有已完成的榜单：
- 按媒介维度分组
- 支持 Row/Col 两种布局切换
- 每个榜单卡片显示第一名的海报
- 可以重命名（点击标题）和删除（点击红色圆点）

### 批注系统

「我的文化索引」页面支持三个层级的批注：

| 层级 | 位置 | Key 格式 |
|------|------|----------|
| 画像整体 | 页面标题右上方 | `profile:<profileId>` |
| 单个榜单 | 榜单标题旁 | `ranking:<kind>:<title>` |
| 单个作品 | 每行右侧 | `work:<kind>:<workId>` |

有批注时便签纸图标加亮为 accent 色并显示文字，无批注时暗色。画像和榜单级别为胶囊按钮样式，更醒目。

**云端同步**：登录状态下，批注数据随画像一起自动同步到云端（页面关闭/切后台/网络恢复时触发）。从云端恢复画像时也会恢复批注。

点击图标打开笔记弹窗：
- **背景**：作品海报的模糊渲染
- **编辑**：文本框自由输入
- **保存**：点击「保存」写入 localStorage
- **清除**：点击「清除」删除该条批注

**分享带批注**：生成比较链接时，如有批注会自动包含在分享数据中。对方打开链接后可看到你的批注。

**导出带批注**：TXT/MD/CSV/JSON 导出均自动包含批注。CSV 新增 `note` 列，TXT/MD 中有批注的作品名后附加批注段落。

批注数据存储在 `art-rank:notes` localStorage key。

### 导出画像

在"我的文化索引"页面可以导出：

| 格式 | 说明 |
|------|------|
| JSON | 推荐用于重新导入和比较，包含完整元数据和批注 |
| TXT | 纯文本格式，有批注的作品名后附加批注段落 |
| Markdown | 带标题和编号列表，批注以引用格式显示 |
| CSV | 电子表格格式，新增 note 列，含防公式注入处理 |
| PNG | 图片格式，三种版式可选 |

**PNG 版式：**
- **编辑型（Editorial）**：海报缩略图 + 标题列表
- **拼贴型（Collage）**：海报网格排列
- **极简型（Minimal）**：纯文字列表

## 相遇：与他人比较

### 分享你的索引

1. 在"相遇"页面点击"复制比较链接"
2. 链接自动复制到剪贴板
3. 同时生成二维码，方便手机扫描
4. 发给对方即可开始比较

链接格式：`/encounter?payload=<压缩编码>` 或 `/encounter?payload=<8位短码>`

### 分享单个榜单

在「我的文化索引」页面，每个榜单的标题区域都有一个「分享此榜单」按钮。点击后生成仅包含该榜单的比较链接，对方打开后可以直接导入这一个榜单进行比较，无需加载你的完整文化索引。

### 导入对方索引

三种方式导入：

1. **打开比较链接**：直接在浏览器打开
2. **粘贴 URL**：在相遇页面粘贴对方的链接
3. **导入 JSON 文件**：上传对方导出的 JSON 文件

### 比较模式

#### 自动合并

同媒介的所有榜单自动合并后比较：
- 同一作品在多个榜单中取最高名次
- 显示来源榜单标签
- 适合有多份同类型榜单的情况

#### 指定榜单

手动勾选双方各哪些榜单参与比较：
- 可以选择不同组合进行对比
- 适合精确控制比较范围

### 比较结果

| 指标 | 说明 |
|------|------|
| 作品重合度 | 共同作品占并集的比例 |
| 加权偏好一致 | 基于排名权重的一致性 |
| 顺序一致率 | 共同作品的排序一致性 |
| Top 3 共识 | 双方前三名中的共同作品数 |
| 名次距离 | 平均名次差异 |
| 冠军一致 | 双方第一名是否相同 |

**共同作品表格**：
- 点击交换按钮可按我的顺序或对方顺序排列
- 点击排名数字可打开该榜单的完整列表
- 点击作品可查看详情（海报、评分、简介）
- 来源标签显示最高排名的榜单名称

**榜单展示**：
- 点击榜单海报区域可打开该榜单的完整排名详情弹窗
- 总榜单数为1的那一方，布局为「榜单名称 | 前三名竖排居中 | Top N」，多方保持单个榜首海报，各自独立判断

### 用对方作品重排序

在比较结果区可选择对方的一个榜单进行排序：
- 弹出面板展示对方所有榜单（不限媒介类型）
- 选择后进入标准排序流程
- 重名榜单自动添加后缀 (2)、(3)...

### AI 解读

点击"生成解读"按钮，AI 会将共同偏好与分歧整理成可读的文化侧写。（需配置 `AI_API_KEY`）

## 用户账号

### 游客模式

- 数据只在浏览器 localStorage
- 可完整使用排序、比较、导出功能
- 不需要登录

### 登录同步

右上角用户按钮会根据登录状态变化：未登录时显示「登录/同步」，已登录时显示「同步/退出」。

支持三种登录方式：
- 邮箱 + 密码注册/登录
- Google OAuth
- GitHub OAuth

登录后：
- 画像自动同步到云端
- 切到后台、网络恢复或关闭页面时自动保存
- 可以管理云端清单
- 同步失败不会覆盖本地画像

### 数据冲突

当本地有游客数据、云端也有数据时，可以选择：
- **增量合并**：合并双方数据到云端
- **使用云端数据**：覆盖本地数据
- **取消**：各自保留

## 常见问题

### 海报为什么是占位？

远程图片可能被上游限流、失效或不是允许的图片 host。Worker 会尝试豆瓣镜像和 IMDb 备用；所有来源失败时仍可正常排序。

### 为什么豆瓣接口返回不可用？

豆瓣页面可能要求验证或限制当前出口。稍后重试，或使用内置榜单 / 自定义清单。部署到 Cloudflare 后，Worker 的出口与本地不同，成功率可能不同。

### 为什么比较链接很长？

未配置 D1 时，画像会压缩到 URL 的 hash 中。作品和维度越多，链接越长；超过浏览器可用长度时请改用 JSON 文件。

### 刷新后没有草稿？

草稿只存在当前浏览器和域名。隐私模式、清理站点数据、换域名或排序已经完成，都会导致找不到草稿。

### 如何清除所有本地数据？

在首页"品味年轮"区域点击"清除数据"按钮，会清除本地的画像、草稿和对方索引。

### 排序中途可以退出吗？

可以。排序进度自动保存为草稿，下次访问首页时可选择"继续上次进度"。

### 两个人可以比较不同媒介吗？

可以。比较会自动找出双方都有的媒介维度进行对比。如果还没有共同维度，可以选择对方的榜单创建自己的排序。
