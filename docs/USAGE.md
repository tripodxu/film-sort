# 使用说明

ART/RANK 是一个交互式艺术偏好排序工具。本指南覆盖从首次使用到高级功能的完整操作流程。

---

## 使用引导与技术说明

### 首次访问

第一次打开网站时会自动弹出使用说明弹窗，展示 5 步快速上手指南：

1. **选择媒介维度** — 电影、书籍、音乐或其他
2. **选择作品来源** — 精选榜单、自定义清单或豆瓣 Top250
3. **1v1 取舍排序** — 点击你更想留下的作品
4. **查看文化索引** — 排序完成后自动保存，可导出多种格式
5. **与朋友比较** — 生成比较链接或二维码

弹窗底部按钮：
- **「知道了」** — 关闭弹窗，下次访问还会自动弹出
- **「不再显示」** — 关闭弹窗并记录到浏览器，之后不再自动弹出

### 帮助按钮

首页右下角有一个固定的 `?` 按钮，点击随时可重新打开使用说明（不受「不再显示」设置影响）。

### 技术说明

在使用说明弹窗底部点击「技术说明」按钮，可查看 ART/RANK 的核心算法和数据流，包含 4 个可折叠板块：

- **排序算法**：主动式二分插入排序（O(n log n)）、配对/作品冷却机制、偏好回环检测（观察中→持久张力）、验证阶段复测、撤销重放机制
- **比较算法**：维度合并策略、贪心匹配算法、6 项比较指标（作品重合度、加权偏好一致、顺序一致率、Top 3 共识、名次距离、斯皮尔曼相关）
- **海报与详情 API**：海报解析优先级（suggest→搜索→Top250→IMDb）、Wikipedia/百度百科详情获取、防限流机制（UA 轮换、域名节流、403/418 重试与冷却）
- **数据存储**：游客 localStorage、登录用户 D1 同步、分享链接服务端 12 位短码（旧版内联压缩链接仍可读）

技术说明底部提供 GitHub 项目链接：[github.com/tripodxu/film-sort](https://github.com/tripodxu/film-sort)

> 更详细的算法与数据流说明见 `ARCHITECTURE.md`；接口细节见 `API.md`。

## 页面路径

每个页面有独立 URL，可直接访问、收藏或分享：

| 路径 | 页面 | 说明 |
|------|------|------|
| `/` | 清单 | 首页，媒介选择入口 |
| `/catalog/source` | 选择来源 | 内置榜单 / 自定义 / 豆瓣 |
| `/catalog/setup` | 配置排序 | Top N、候选作品筛选 |
| `/catalog/sorting` | 排序中 | 1v1 取舍界面 |
| `/encounter` | 相遇 | 与他人比较 |
| `/encounter?payload=<code>` | 相遇 | 通过分享链接导入对方索引 |
| `/myself` | 我的文化索引 | 已完成的榜单和画像 |
| `/share/:code` | 查看分享 | 查看他人分享的榜单/画像 |
| `/plaza` | 广场 | 公共信息流，浏览和互动 |
| `/plaza/:id` | 广场帖子详情 | 单个帖子详情 + 留言 |

- 所有页面支持浏览器前进/后退、直接输入路径访问、书签收藏。
- `?lang=en` 参数在页面切换时保留，可随时切换中英文。
- 顶栏调色板图标可切换六套界面主题（现代/复古纸感/极简/简约/古典/赛博朋克），选择记住在本地；PNG 导出跟随当前主题。

## 快速开始

### 第一步：选择媒介

打开首页，选择一个媒介维度开始：

- **电影** — 镜头、人物与记忆
- **书籍** — 句子、思想与世界
- **音乐** — 旋律、歌词与身体
- **其他** — 任何值得留下的作品（游戏、展览、播客等）

每个媒介可以创建多个独立榜单，完成后并入同一个艺术人格画像。

### 第二步：选择作品

进入清单选择页后，有三种方式获取作品：

#### 精选清单

内置的精选榜单，涵盖经典电影、文学、音乐等。可以：
- 搜索榜单名称、说明或其中的作品名
- 切换 2/3/4 列布局（点击列数按钮）
- 点击榜单进入详情

#### 我的清单

**即搜即加**（推荐）：输入框键入标题回车即搜索，弹出带海报的候选，点选加入右侧清单；候选都不对时可「仅以标题加入」。
- 电影/书籍/音乐 → 搜豆瓣；**其他** → 搜维基百科（自动带配图与简介）。
- 右侧「已添加作品」为海报卡片网格，可单件移除或清空，≥2 件即可开始排序。

**批量导入**（折叠面板）：每行一件，支持逗号、顿号、分号分隔，或 TXT/JSON 文件（2–1000 件，标题 ≤160 字符，海报 URL 须 HTTPS）。

**外部导入**（登录后可用，点区块右上 `?` 看完整图文说明）：

| 来源 | 用法 | 说明 |
|---|---|---|
| 豆瓣豆列 | 粘贴 `douban.com/doulist/…` 链接 | 抓整份豆列（标题/创作者/年份/评分/海报） |
| 豆瓣书影音清单 | 粘贴 `m.douban.com/subject_collection/…` | 官方书单/片单，公开无需登录 |
| 我的想看/已看 | 连接豆瓣后一键按钮，或粘贴 `…/mine?status=wish\|collect` | 电影「想看/已看」、书籍「想读/已读」；需先连接 |
| 网易云按 UID 浏览 | 输入用户 ID 或主页链接 → 浏览歌单 | 列出该用户**全部歌单（含收藏的）**，点选任意一个导入整单歌曲；无需连接网易云 |
| 网易云歌单直链 | 粘贴歌单链接或 ID | 公开歌单直接抓；私有歌单与「我喜欢的音乐」需先连接 |

> 网易云偶尔会限制服务器匿名访问（列表为空并提示）。展开「连接我的网易云账号（扫码 / 粘贴 Cookie）」连接后即可恢复，且能浏览/导入自己的私有歌单。

> 清单很长时，可在顶栏右上角的「设置」里把「单次导入上限」调到 500 / 1000（默认 300）；再次导入即可继续抓取后续部分。

**连接方式**（豆列/mine/私有歌单的前置，二选一）：
- **扫码**：点「扫码连接豆瓣 / 网易云」，App 扫一扫 → 手机确认。弹窗有大码 + 倒计时（归零自动换码，最多 2 次）。
- **粘贴 Cookie**：扫码被风控拒绝时弹窗自动展开降级卡；或点「粘贴 Cookie 连接」。电脑浏览器登录对应网站 → F12 Network → 任意请求的 Request Headers 里复制含 `dbcl2=`（豆瓣）或 `MUSIC_U=`（网易云）的 cookie 整段粘贴。

凭证以 AES-GCM 加密存储、只用于读取你的清单，点「断开连接」立即删除。

**云端同步**：登录后清单自动存云端，「我的云端清单」区可复用/删除。

**JSON 格式示例：**
```json
[
  {"title": "Kind of Blue", "creator": "Miles Davis", "year": 1959},
  {"title": "Blue", "creator": "Joni Mitchell", "year": 1971}
]
```

#### 豆瓣精选

从豆瓣 Top250 获取候选作品：
- 选择 Top 25 / 50 / 100 / 250
- 点击"读取榜单"
- 豆瓣可能要求验证或限流，可稍后重试或使用其他来源

### 第三步：配置排序

打开榜单后进入配置页：
- **选择候选**：勾选/取消作品，至少保留 2 件
- **排序模式**：三选一（选择会被记住）——
  - *简易*：每件新作品只与榜单末位比一次，赢了上榜、输了直接出局；大清单（上百件）快速挖 Top N 的首选
  - *经典*（默认，推荐）：二分定位 + 偏好回环检测 + 完成前复测
  - *精确*：在经典之上加倍复测、主动补验未直接比较过的相邻对，完成后汇报"校准一致率"
- **设置 Top N**：用滑块或直接输入数字，设定你想保留的排名数量
- **顺序口令**：可选，相同的口令会产生相同的初始展示顺序
- **榜单名称**：自定义名称

点击"开始相遇"进入排序。排序页会显示当前模式；简易模式满员后会提示"守门员模式：新作品赢过榜单末位即可上榜"。

### 第四步：1v1 取舍

每次看到两件作品，选择你更想留下的那一件：

| 操作 | 效果 |
|------|------|
| 点击左/右卡片 | 选择更偏好的作品 |
| `A` / `←` / `1` | 选择左侧作品 |
| `D` / `→` / `2` | 选择右侧作品 |
| 撤销按钮 | 回到上一次选择 |
| 略过按钮 | 不把该作品放入排名 |
| 暂放按钮 | 暂时移到队列后面 |

**排序进度**：顶部显示已处理数量、比较次数和预计剩余。

**偏好回环**：如果发现 A 比 B 好、B 比 C 好、但 C 比 A 好的矛盾，系统会安排复测；该回环多次一致出现时会提示把它保留为你的真实张力，不会强行改写你的结果。

**验证阶段**：主排序完成后，会自动复测少量相近取舍，让结果更准确。

**快捷键**：输入框获得焦点时不会触发。

**草稿保存**：排序进度自动保存到浏览器，刷新或重新打开首页后可选择"继续上次进度"。

### 第五步：查看结果

排序完成后自动保存到画像。可以在"我的文化索引"页面：
- 切换不同媒介维度
- 查看完整排名（前三名有奖牌 🥇🥈🥉）
- 重新排序、改名、删除榜单（榜单动作栏的 ⋯ 菜单；删除有红色确认条）

## 艺术人格画像

### 品味年轮

首页的"品味年轮"区域展示所有已完成的榜单：
- 按媒介维度分组
- 支持 Row/Col 两种布局切换
- 每个榜单卡片显示第一名的海报
- 可以重命名（点击卡片右上角的黄色圆点）和删除（点击红色圆点）

### 批注系统

「我的文化索引」页面支持三个层级的批注：

| 层级 | 位置 | Key 格式 |
|------|------|----------|
| 画像整体 | 页面右上工具条 | `profile:<profileId>` |
| 单个榜单 | 榜单标题旁 | `ranking:<kind>:<title>` |
| 单个作品 | 每行右侧 | `work:<kind>:<workId>` |

有批注时便签纸图标加亮为 accent 色并显示文字，无批注时暗色。画像和榜单级别为胶囊按钮样式，更醒目。

**云端同步**：登录状态下，批注数据随画像一起自动同步到云端（页面关闭/切后台/网络恢复时触发）。从云端恢复画像时也会恢复批注。

点击图标打开笔记弹窗：
- **背景**：作品海报的模糊渲染
- **编辑**：大面积写作框，适合书写感想和回忆
- **保存**：点击「保存」写入 localStorage
- **清除**：点击「清除」删除该条批注

长批注在展示时截断为 30 字，点击「查看全文」在毛玻璃阅读弹窗中查看完整内容（海报模糊背景）。

**分享带批注**：生成比较链接时，如有批注会自动包含在分享数据中。对方打开链接后可看到你的批注。

**导出带批注**：TXT/MD/CSV/JSON 导出均自动包含批注。CSV 新增 `note` 列，TXT/MD 中有批注的作品名后附加批注段落。

批注数据存储在 `art-rank:notes` localStorage key。

### 导出画像

在"我的文化索引"页面可以导出：

| 格式 | 说明 |
|------|------|
| JSON | 推荐用于重新导入和比较，包含完整元数据和批注 |
| TXT | 纯文本格式，有批注的作品名后附加批注段落 |
| Markdown | 带标题和编号列表，批注以引用格式显示 |
| CSV | 电子表格格式，新增 note 列，含防公式注入处理 |
| PNG | 图片格式，五套版式可选，**跟随当前主题配色**，2x 高清，文件名含画像名+日期 |

**PNG 版式**（导出格式选 PNG 后出现版式切换器）：
- **编辑（Editorial）**：每个榜单首件大图 + 双列名录，杂志感
- **领奖台（Podium）**：前三名大海报 + 金银铜奖牌台座，其余小字名录
- **拼贴（Collage）**：海报网格、微旋转错落
- **胶片（Filmstrip）**：横排缩略 + 齿孔装饰
- **极简（Minimal）**：纯文字编号列表

导出图配色取自当前所选主题（现代/复古/极简/简约/古典/赛博朋克），换主题再导出即得对应风格的图。

## 相遇：与他人比较

### 分享你的索引

有两种链接类型，用途不同：

| 按钮 | 链接格式 | 对方打开后 |
|------|----------|------------|
| **比较链接** | `/encounter?payload=<8–12位短码>` | 直接进入比较界面 |
| **分享链接** | `/share/<8–12位短码>` | 进入查看页面，展示榜单内容（含批注），可选择排序或比较 |

**生成方式：**
1. 在「我的文化索引」页面，右侧工具栏有「复制比较链接」和「复制分享链接」两个按钮
2. 每个榜单的动作栏 ⋯ 菜单里也有该榜单的「比较链接」和「分享链接」
3. 在「相遇」页面，有「比较链接」和「分享链接」两个按钮（分享完整画像）
4. 点击后链接自动复制到剪贴板
5. 比较链接同时生成二维码，方便手机扫描

### 分享单个榜单

在「我的文化索引」页面，每个榜单的动作栏 ⋯ 菜单里都有「比较链接」和「分享链接」按钮：
- **比较链接**：对方打开后直接进入比较界面
- **分享链接**：对方打开后进入查看页面，展示榜单内容和批注

### 导入对方索引

三种方式导入：

1. **打开比较链接**：直接在浏览器打开
2. **粘贴 URL**：在相遇页面粘贴对方的链接
3. **导入 JSON 文件**：上传对方导出的 JSON 文件

### 比较模式

#### 自动合并

同媒介的所有榜单自动合并后比较：
- 同一作品在多个榜单中取最高名次
- 显示来源榜单标签
- 适合有多份同类型榜单的情况

#### 指定榜单

手动勾选双方各哪些榜单参与比较：
- 可以选择不同组合进行对比
- 适合精确控制比较范围

### 比较深度

比较页"比较深度"可选三档（选择会被记住）：

- **简易**：只保留共识圆环与三项主指标（重合度 / 顺序一致率 / Top 3 共识），一眼看结论
- **经典**（默认）：展开全部指标、共同作品表与名次分歧 Top 5
- **精确**：默认展开"更多指标"，新增"共识构成"五因子贡献条（看清综合分怎么来的）与"全部名次分歧"表；多榜单合并改按**名次中位数**聚合（对单一异常榜单更稳健）

### 比较结果

比较页顶部是**综合共识评分圆环**（0-100 + 判词，由下列指标加权合成），下方主指标网格，「更多指标」可展开，每项带 `?` 悬浮解释。

| 指标 | 说明 |
|------|------|
| 作品重合度 | 共同作品占并集的比例 |
| 顺序一致率 | 共同作品相对先后次序一致的比例（并列名次剔除，相同画像=100%） |
| 加权偏好一致 | 基于排名权重（越靠前越重要）的一致性 |
| 名次距离 | 平均名次差异（越低越一致） |
| 冠军一致 | 双方第一名是否相同 |
| Top 3 共识 | 双方前三名中的共同作品数 |
| Spearman 一致 | 名次差平方和换算的秩相关 |
| Kendall τ | 含并列的序对一致度（50=无关，100=完全一致） |
| 前五重合 | 双方 Top-5 集合的 Jaccard 相似度 |
| 年代偏好 | 双方榜单年代中位数的接近程度 |

**共同作品表格**：
- 点击交换按钮可按我的顺序或对方顺序排列
- 点击排名数字可打开该榜单的完整列表
- 点击作品可查看详情（海报、评分、简介）
- 来源标签显示最高排名的榜单名称

**榜单展示**：
- 点击榜单海报区域可打开该榜单的完整排名详情弹窗
- 总榜单数为1的那一方，布局为「榜单名称 | 前三名竖排居中 | Top N」，多方保持单个榜首海报，各自独立判断

### 用对方作品重排序

在比较结果区可选择对方的一个榜单进行排序：
- 弹出面板展示对方所有榜单（不限媒介类型）
- 选择后进入标准排序流程
- 重名榜单自动添加后缀 (2)、(3)...

### AI 解读

比较页的「AI 观察」卡会基于比较指标（重合度、共识评分、最大分歧等）生成跨媒介解读，点击「生成点评」才开始请求。生成前可选输出长度：**简短 / 标准 / 深入**（选择会被记住）。

### AI 点评榜单与画像

在「我的文化索引」页：

- 榜单操作栏的「AI 点评」：对当前这份榜单生成品味侧写（总体印象 / 品味亮点 / 盲区）；
- 顶部的「AI 点评画像」：基于你全部榜单与高频创作者给出整体的艺术人格点评。

同一份内容生成的点评在当前会话内会缓存（换长度或数据变化后重新生成）。

### 配置自己的 AI（可选）

默认使用服务端内置模型。若想用自己账号下的模型服务：顶栏「设置 → AI 解读服务」，填入三参数——

1. **Base URL**（填到 `/v1` 这一级，如 `https://api.openai.com/v1`）；
2. **API Key**；
3. **Model**（可点「获取模型列表」直接点选）。

协议默认自动探测，也可手动指定 Chat Completions / Responses API / Anthropic Messages / Gemini Native；建议先点「测试连接」确认。Key 只保存在你自己的浏览器，点评时会把榜单标题发送给你配置的服务；清除配置即可回到内置通道。

如果生成失败，提示会区分原因：操作太频繁（限流，附等待时长）、API Key 无效、接口地址或协议不匹配、服务暂不可用——按提示调整即可。

## 查看分享

直接在浏览器打开分享链接（如 `/share/:code`）时，不再直接跳入比较，而是进入查看页面：

1. 展示对方榜单/画像的完整内容（含批注）
2. 查看前三名海报、作品列表和排名
3. 选择下一步操作：
   - **用此榜单排序** — 进入标准排序流程，候选作品来自对方榜单（分享内容含多个榜单时，该按钮出现在每个榜单标题处）
   - **与我比较** — 跳转到相遇页面，自动导入对方数据（需先有自己的画像）
   - **复制分享链接** — 复制当前链接转发给其他人

> 若你还没有画像，查看页下方会给出「如何创建自己的分享链接？」的三步说明和「开始创建我的榜单」入口。

> 注意：在「相遇」页面粘贴链接的行为不变，仍直接进入比较界面。

## 广场

### 浏览广场

访问 `/plaza` 进入广场。广场是公开的信息流，未登录也能浏览、搜索和用他人榜单排序：

- **筛选**：顶部可选择全部、电影、书籍、音乐或其他媒介
- **排序**：支持最新和最热两种排序方式
- **帖子卡片**：每个帖子显示前三名海报、榜单名称、发布者昵称、媒介类型、作品数、发布时间、点赞数和留言数
- **分页**：滚动到底部自动加载更多（也保留「加载更多」按钮）

### 查看帖子详情

点击帖子卡片进入 `/plaza/:id` 详情页：
- 查看完整排名列表（前三名有奖牌 🥇🥈🥉）
- 查看批注（如有）
- 查看和发表留言

### 发布到广场

在「我的文化索引」页面，每个榜单的动作栏有「发布」按钮（仅登录用户可见），画像右上角另有「发布画像」：

1. 点击后打开「发布到广场」弹窗
2. 可输入「榜单描述」（可选，最多 500 字）
3. 点击弹窗右下角的「发布」确认，成功后有粒子动效与通知
4. 该榜单相关的批注会随帖子一并发布，其他用户可在广场看到

发布画像（多维度文化索引）也用同一个弹窗。

### 互动

- **点赞**：帖子详情页有「赞」按钮（带计数），点击切换（需登录）。列表卡片只显示点赞数，不能直接点赞
- **留言**：在帖子详情页底部输入评论（最长 500 字，需登录）。支持回复其他评论，形成嵌套讨论
- **用此榜单排序**：使用该帖子的作品列表进入排序流程
- **与我比较**：将该帖子数据导入相遇页面进行比较

### 作者管理自己的帖子

帖子详情页对作者显示管理按钮（服务端 `is_author` 判定，无需自己记得是谁发的）：
- **编辑榜单**（榜单帖）：拖拽或 ↑↓ 改序、移除作品、按「标题 - 创作者（年份）」手动增删，另可改描述
- **编辑信息**（画像帖）/ **编辑描述**（榜单帖）：改描述；画像帖可勾选「同时用我当前的画像数据覆盖帖子内容（榜单/作品/批注）」同步最新排序
- **隐藏 / 恢复**：隐藏后广场列表不再展示，仅自己可见（详情页有黄色提示条），随时可恢复
- **删除**：二次确认后删除，连同点赞/留言/编辑历史一并清理
- **编辑历史**：每次操作（改序/增删/同步/隐藏…）都有服务端时间戳记录，仅作者可见；帖子公开显示「最后编辑于 …」
- 自己的帖子按钮文案为「与曾经的我比较」，对比发布时的旧版本与现在的排序差异

留言作者可以删除自己的留言。

## 人工优化排序

排序完成后，如果对结果不满意，支持手动调整排名：

### 进入方式

在「我的文化索引」页面，每个榜单的动作栏有「手动调整」按钮。

### 操作方式

进入拖拽排序模式后：

- **拖拽**：每个作品行左侧有拖拽手柄，拖动作品行调整位置
- **上下箭头**：使用上下箭头按钮逐位移动作品
- **实时更新**：排名数字随调整实时更新
- **保存**：点击「保存」更新本地画像并同步到云端
- **广场同步**：手动调整保存后不会自动改写广场帖子；「编辑作品」保存后会出现「该榜单已发布到广场…」提示条，在那里点「同步到广场」即可更新帖子排序

### 适用场景

- 对算法排序结果不满意，想微调个别作品的排名
- 有一个心目中的排名，想手动快速输入（而不是重新排序）
- 发布到广场前想对排名做最后调整

## 用户账号

### 游客模式

- 数据只在浏览器 localStorage
- 可完整使用排序、比较、导出功能
- 不需要登录

### 登录同步

右上角用户按钮会根据登录状态变化：未登录时显示「登录/同步」，已登录时显示「同步/退出」。

支持三种登录方式：
- 邮箱 + 密码注册/登录
- Google OAuth
- GitHub OAuth

登录后：
- 画像和批注自动同步到云端
- 切到后台、网络恢复或关闭页面时自动保存
- 可以管理云端清单
- 同步失败不会覆盖本地画像

退出登录时：
- 先将画像和批注同步到云端（keepalive 模式）
- 然后清除本地所有数据（画像、批注、草稿、对方索引）

### 数据冲突

当本地有游客数据、云端也有数据时，可以选择：
- **增量合并到云端**：合并双方数据到云端
- **使用云端数据**：覆盖本地数据
- **取消，各自保留**

## 常见问题

### 海报为什么是占位？

远程图片可能被上游限流、失效或不是允许的图片 host。Worker 会尝试豆瓣镜像和 IMDb 备用；所有来源失败时仍可正常排序。

### 为什么豆瓣接口返回不可用？

豆瓣页面可能要求验证或限制当前出口。稍后重试，或使用内置榜单 / 自定义清单。部署到 Cloudflare 后，Worker 的出口与本地不同，成功率可能不同。

### 为什么生成分享 / 比较链接会失败？

分享与比较链接都由服务端短链服务生成（`POST /api/share`）。未配置 D1 或请求失败时页面会提示"生成链接失败，请导出 JSON 分享"，此时请改用导出的 JSON 文件分享给对方。

### 刷新后没有草稿？

草稿只存在当前浏览器和域名。隐私模式、清理站点数据、换域名或排序已经完成，都会导致找不到草稿。

### 如何清除所有本地数据？

在首页"品味年轮"区域点击"清除数据"按钮，会清除本地的画像、草稿和对方索引。

### 排序中途可以退出吗？

可以。排序进度自动保存为草稿，下次访问首页时可选择"继续上次进度"。

### 两个人可以比较不同媒介吗？

可以。比较会自动找出双方都有的媒介维度进行对比。如果还没有共同维度，可以选择对方的榜单创建自己的排序。
