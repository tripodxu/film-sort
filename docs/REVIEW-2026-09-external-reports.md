## 五、P0 已实施（3 个提交）

| 提交 | 内容 |
|------|------|
| `464775b` | 接入 Prettier / ESLint 工具链并全仓统一格式 |
| `604d331` | 修掉两处 Hook 违规 + 首屏光球移出关键路径（N1、N3） |
| `9f36ae9` | 限流窗口 Map 加上界与惰性清扫 |

**P0-1 首屏光球**（对应 N1）：新增 `src/components/DeferredOrb.tsx`。省流 / 2G 网络完全不加载；
其余情况等首屏空闲（`requestIdleCallback`，2s 上限）再 `import()`；等待期间渲染与 `OrbScene`
根节点同 class 的占位元素，无 CLS。

> **口径修正**：这一步把 132 KB gzip 从**首屏关键路径**上摘下来（并让省流 / 2G 用户完全省掉），
> **不是**把页面总传输量减少 132 KB——留在页面上的用户仍会在空闲时加载它。
> `prefers-reduced-motion` 刻意不拦截：`OrbScene` 内部已把该偏好处理成"只渲染一帧静止画面"，
> 跳过加载反而会让那些用户从"静态光球"变成"没有光球"，属视觉回归。

**P0-2 限流窗口**（对应报告第 1 条说得对的部分）：抽到 `worker/rateWindow.ts`，保留逐字等价的
判定行为，新增惰性清扫（先删到期条目，仍超 5000 条才按插入顺序淘汰）。淘汰只会放宽不会收紧。
新增 7 项单测。

**P0-3 工具链**（对应报告第 2 条）：ESLint 首轮只开 `react-hooks/recommended` 与
`no-unused-vars(warn)`，避免全仓开火产生上千条告警把信号淹掉。它立刻抓到 **2 个 error**——
其中一个（`PlazaView.tsx` 的 `useForSorting`）是我自己在核验报告时**没有发现**的：那是个普通
事件处理器，只是名字带了 `use` 前缀，却被 lint 当成自定义 Hook 在 `onClick` 里调用。已改名为
`sortWithPost`。
**P0-4 巨行**（对应 N2）：全仓 Prettier 后最长单行 10,539 → 252 字符。

### 格式化的等价性验证

不靠肉眼：把 HEAD 与工作区的每个 `.ts/.tsx` 分别交给 esbuild 压成 minified 产物再逐字节比较
（JSX 文本在转换后就是字符串字面量，任何文案空白变化都会暴露）；CSS 用 postcss 解析后逐节点
比较；JSON 剥注释后按结构比较。**67 个代码文件全部通过。**

该检查也确实抓到过一次真实差异：`src/styles.css` 里的 `content:"\25B8"` 被 Prettier 改写成
`content:" \25B8 "`——按 CSS 转义规则，转义后的那个空格会被当作终止符吃掉，字符串凭空多出
一个前导空格，折叠标记会真的位移。因此 **`src/styles.css` 被排除在格式化之外**（详见
`OPTIMIZATION.md` §5.3）。

### 实施过程中新发现

- **`src/styles.css` 里有 4 处 U+FFFD 损坏的 `content` 声明**（装饰箭头被编码破坏，字符串
  未闭合，`vite build` 每次都会警告）。**历史遗留**：`git show HEAD:src/styles.css` 里同样存在。
  已登记在 `OPTIMIZATION.md` §5.3，修复需要判断每处原本是哪个箭头，需与 CSS 可维护性一起处理。
- 我自己在核验报告时列了 N1–N6，但漏掉了 N3 之外的另一处同类问题（`useForSorting` 命名），
  是 ESLint 抓到的。**审查清单不如可执行的门禁可靠**。

## 七、明确不建议做的事

来自报告建议、但经核验应当拒绝的项：

| 建议 | 判断 | 理由 |
|---|---|---|
| 迁移 Next.js / Remix | **不做** | 当前是 CF Worker + 静态资源 + D1；换框架是重写，收益为零 |
| 引入 Zustand / Jotai | **不做** | 状态已收敛在两个 Hook + `deps` 对象内；引入 store 会增加体积（正是报告自己抱怨的那项） |
| 引入 Zod 做运行时校验 | **不做** | 约 +13 KB gzip，加在报告自称"过大"的 bundle 上；现有容错解析器 + 179 项测试已覆盖同一边界 |
| 所有敏感操作加 CSRF Token | **不做** | 变更类接口用 Bearer token，无 cookie 认证，经典 CSRF 不适用；唯一的 cookie（`oauth_state`）已是 `HttpOnly + SameSite=Lax` 且做了严格比对。写接口已有 `assertSameOrigin()` 同源校验（`worker/index.ts`），再加一套 token 是重复防护 |
| localStorage 读写锁 / 改 IndexedDB | **不做** | 同步单线程 API 不存在读写竞态。若在意的是**多标签页**覆盖，正确做法是监听 `storage` 事件 |
| 把 `console.error(e)` 降级为只记 `e.message` | **不做** | 服务端日志对用户不可见，丢掉堆栈只会让 N4 这类问题更难查 |
| 音乐取图改串行"短路" | **不做** | 会在"网易云失败"这条用户已经在等的路径上再叠一次豆瓣往返。正确做法是先测量来源胜出比再决定 |
| "基于机器学习优化匹配算法" | **不做** | 切入点其实是繁简归一（一行映射表），上模型是把可解释规则换成不可解释的成本 |
